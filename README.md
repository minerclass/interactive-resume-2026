# interactive-resume-2026

This repository turns a traditional resume into an interactive public portfolio for GitHub Pages. It is designed as an extension of the resume rather than a replacement for it: the site helps visitors explore leadership experience, AI governance work, publications, speaking, research themes, and project evidence in a more navigable format.

## What This Includes

- A GitHub Pages-ready interactive site in `docs/`
- Filterable experience, publications, speaking, and project sections
- A leadership evidence map organized around K-12 technology leadership, AI governance, curriculum, research, and public scholarship
- A privacy-conscious public-facing contact section
- A structure that can be expanded with GitHub repository links, PDFs, slide decks, writing samples, and artifacts

## Publish on GitHub Pages

1. Create a new GitHub repository named `interactive-resume-2026`.
2. Add the contents of this folder to that repository.
3. Push the repository to GitHub.
4. In GitHub, open **Settings** -> **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the default branch and the `/docs` folder.
7. Save.

GitHub Pages will publish the site at:

```text
https://minerclass.github.io/interactive-resume-2026/
```

## Local Preview

Open `docs/index.html` in a browser. No build tools, package manager, server, or external JavaScript dependencies are required.

## Suggested Next Additions

- Add downloadable PDFs, slide decks, or writing samples under `docs/assets/`.
- Add a short `case-studies/` folder with one Markdown file per major project.
- Add `resume.pdf` only if the public version has been reviewed for personal information.
- After publishing, enable GitHub Pages from the `/docs` folder.

## Privacy Notes

This version avoids a home street address and does not include sensitive district systems, private research participant data, student data, credentials, internal links, or unpublished interview materials.

Before publishing, review all contact details and artifacts for:

- Personal addresses
- Student or staff information
- Private district URLs
- Unpublished dissertation participant data
- Vendor contracts or implementation details that should not be public
